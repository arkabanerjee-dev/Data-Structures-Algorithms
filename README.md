# Data Structures and Algorithms

Practice repository for learning Data Structures and Algorithms (DSA) in Python.

## About

This repo contains my practice code while learning DSA concepts in Python. Each file covers the basics of one data structure.

## Structure

src/
-  List_basic_methd.py  - basic list methods
- set_basics.py        - basic set operations
- tuple_basics.py      - basic tuple operations

## Requirements

Python 3.x

## How to Run

python src/<file_name>.py

Example:
python src/set_basics.py
